# Agent Examples

Simulated Telegram conversations showing what each bot looks like in practice.
These use a generic setup: user named "Alex", projects "Startup" and "Freelance".

| File | What it shows |
|------|--------------|
| `diario_bot.md` | Full day flow — morning kickoff → task capture → evening review |
| `admin_bot.md` | Typical queries — commitments, project context, system status |

---

Both bots live in a Telegram supergroup with separate topics.
Your agent name is configured in `config.json` → `agent.name`.
